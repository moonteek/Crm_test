# Holidays (Bayram kunlari) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Centre-wide closed days that aren't charged, paid, marked or counted in the course plan.

**Architecture:** A `Holiday` table of calendar days; pure functions in billing and curriculum take the holiday days as a required `holidays: string[]` (ISO `YYYY-MM-DD`) so the compiler finds every caller; one server helper loads them; the UI greys holiday columns and lists holidays in Settings.

**Tech Stack:** Next.js 15, Prisma 6 / SQLite `db push`, node:test.

**Spec:** `docs/superpowers/specs/2026-10-12-holidays-design.md`

## Global Constraints

- Money changes only in per-lesson months (≥ `PER_LESSON_FROM`, Nov 2026); legacy months ignore holidays.
- `lessons` (denominator) = scheduled days; `billable` and `lessonValues` = held days only; `charge = round((price − discount) × billable ÷ lessons)`.
- Holidays from this month onward only (centre calendar); delete only while the date is in the future; duplicates refused with the existing name.
- Permission `holidays.manage` "Bayram kunlari" (default role Menejer); log action `holiday.manage`; never inside `$transaction`.
- With no holidays every balance and salary equals master.

## Review Focus

- A balance page that forgets to load holidays → compile error (field required), checked by `npm run lint` in Task 2.
- Holiday on the group's level-exam day moves the exam to the last held lesson; a window whose every lesson is a holiday has no exam → Task 3 tests.
- Attendance toggled by a crafted request on a holiday is refused server-side → Task 3 action check.
- A holiday range spanning months (31 Dec – 2 Jan) creates three rows → Task 1 test of `expandRange`.
- Today being a holiday: dashboard "today's lessons" and timetable show the message, not lessons → Task 3 browser check.

**Produces:**

- `canDeleteHoliday(date: Date, today: Date): boolean` (date after the centre's today).
- `holidayDays(): Promise<string[]>` in `holidays-db.ts` (server-only, cached per request with React `cache`).
