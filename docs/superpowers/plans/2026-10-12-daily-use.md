# Daily-use Fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Faster, safer daily screens: student search, one debtor count, a helpful payment form, who-took-it + editable payments with history, today's attendance with a late mark, unmarked-groups view, safer group delete, grouped sidebar, timetable export.

**Architecture:** Pure helpers (tested) for every rule; schema additions on Payment/PaymentEdit/Attendance; UI changes in the existing pages and components.

**Tech Stack:** Next.js 15, React 19, Prisma 6 / SQLite, node:test.

**Spec:** `docs/superpowers/specs/2026-10-12-daily-use-design.md`

## Global Constraints

- Balances change only through payment amounts; "Qaysi oy uchun" is a label. With no edits, balances and salaries equal master.
- New permission `payments.edit` "To'lovni tahrirlash" (Administrator only by default).
- Attendance: `late` only with `present: true`; % counts late as present; export mark "K".
- Davomat qilinmagan = active group, lesson today, not a holiday, start time passed (centre time), no mark today.
- Search: students only, ≥ 2 characters, ≤ 8 results, `studentScope`, balance chip only with `canSeeBalances`.
- Never `logAction` in a transaction; tokens only; refusable dialogs keep typed values.

## Review Focus

- A teacher calling `/api/search/students` gets only their students and no balances → Task 1 route uses `studentScope` + `canSeeBalances`.
- Editing a payment's amount changes that student's balance by exactly the difference and nothing else → Task 2 evidence.
- "Hammasi keldi" doesn't overwrite students already marked absent/late → Task 3 test of `fillPresent`.
- A group whose lesson starts later today isn't "unmarked" yet → Task 3 `unmarkedToday` test.
- A sidebar section with no allowed items disappears (teacher's menu) → Task 4 `navSections` test.
