# Students 1b-i Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Richer student records (fields, tags, notes, history), a filterable paged student list, and Excel / Google Sheets export on every list.

**Architecture:** New Prisma models for tags and notes plus `AuditLog.studentId`; pure, tested helpers for filters, history and export rows; each list's query moves into a loader in `src/lib/lists/` shared by its page and an `export/route.ts` that answers xlsx or tsv.

**Tech Stack:** Next.js 15 App Router (pages, server actions, route handlers), React 19, Prisma 6 / SQLite `db push`, Tailwind v4 tokens, `exceljs` (new dependency), node:test via `npm test`.

**Spec:** `docs/superpowers/specs/2026-10-11-students-1b-design.md`

## Global Constraints

- Nothing in this plan changes money: balances and salaries must equal master afterwards.
- Teachers / assistant teachers (no `students.manage`) can't add notes, attach tags or edit students; tag list needs new permission `students.tags` ("Teglarni boshqarish"), given to default role "Menejer".
- Passport: shown/edited only with `students.manage`; never in any export.
- Export = every row matching the page's current filters (all pages), with the page's own permission and scope; columns a role can't see on the page are left out. Money cells are numbers; dates `DD.MM.YYYY`.
- Sheets copy message: "Nusxa olindi — Google Sheets'da Ctrl+V bosing". Excel file name `<Title>-YYYY-MM-DD.xlsx`.
- Never `logAction` inside `db.$transaction`; colours via tokens only (`npm run check:colors`); forms submit via hidden inputs; dialogs that can be refused keep typed values (onSubmit + startTransition).
- `source` values = `LEAD_SOURCES`; tag colours `TAG_COLORS = ["amber","green","red","blue","grey"]`.

## Review Focus

- A teacher calling the student export route directly gets only their own students and no balance column → Task 4 route test via `studentWhere` scope + browser check as Aziz.
- Uzbek apostrophes ("O'g'il", "Qo'shimcha") and cells containing tabs/newlines must not break TSV columns or Excel text → Task 1 `toTsv` / `toXlsx` tests.
- Status "Qarzdor" for a role without balances must be ignored, not leak debtors → Task 4 `parseStudentFilters` test.
- Pinning a note unpins the previously pinned one (never two pinned) → Task 3 browser + action uses one transaction.
- `?page=` past the end or `per=999` → clamps to last page / allowed sizes → Task 4 test.

### Task 1: Export core

**Files:** Create `src/lib/export.ts`, `src/lib/export.test.ts`, `src/components/ExportButtons.tsx`; Modify `package.json` (add `exceljs`).

**Produces:**
- `type Table = { title: string; columns: string[]; rows: (string | number | null)[][] }`
- `toTsv(t: Table): string` — header + rows, `\t`/`\n` inside cells replaced by a space, `null` → empty.
- `toXlsx(t: Table): Promise<Buffer>` — one sheet named `t.title` (max 31 chars), bold header, column widths from longest cell (min 8, max 50), numbers stay numbers.
- `respondTable(t: Table, format: string | null): Promise<Response>` — `tsv` → `text/tab-separated-values; charset=utf-8`; anything else → xlsx with `Content-Disposition: attachment; filename*=UTF-8''<encoded title>-YYYY-MM-DD.xlsx` (centre date).
- `fmtDate(d: Date | null): string` → `DD.MM.YYYY` or "".
- `<ExportButtons href="/students/export" />` (client): reads current `useSearchParams()`; "Excel" link to `href?<params>&format=xlsx`; "Google Sheets" fetches `format=tsv`, writes to clipboard, shows the copy message (or the error text) for 4 s.

- [ ] Step 2: `npm test` → FAIL (module missing). `npm i exceljs@4.4.0`.
- [ ] Step 3: implement; `npm test` green; lint.
- [ ] Step 4: commit `feat(export): Excel and Google Sheets export core`.
